OPTION B: RECOMMENDED - Local Python Installation
───────────────────────────────────────────────────

STEP 1: Install Python 3.11+
  Windows:
    → Download: https://www.python.org/downloads/
    → Run installer (CHECK "Add Python to PATH")
    → Verify: Open PowerShell, type: python --version
  
  Mac:
    brew install python3
  
  Linux:
    sudo apt-get install python3 python3-pip

STEP 2: Install Dependencies
  Open PowerShell/Terminal in d:\QuishGuard folder:
  
  cd d:\QuishGuard\backend
  pip install -r requirements.txt
  
  This will take 2-3 minutes (installs FastAPI, OpenCV, Google Gemini, etc.)

STEP 3: Run the Backend
  cd d:\QuishGuard\backend
  python main.py
  
  You should see:
  ✓ Uvicorn running on http://0.0.0.0:8000
  
STEP 4: Keep running & open frontend
  Leave that terminal open (backend running in background)
  Then open: file:///d:/QuishGuard/frontend/index.html in your browser
  
STEP 5: Test!
  Try pasting: https://paypal.com
  Or: https://paytm-verify.xyz/login
  
  You should get instant fraud verdicts!

OPTION C: Docker (Advanced - if you prefer containers)
──────────────────────────────────────

1. Install Docker Desktop: https://www.docker.com/products/docker-desktop
2. Open PowerShell in d:\QuishGuard
3. Run: docker-compose up
4. Open: http://localhost:3000
